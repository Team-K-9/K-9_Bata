# 検索機能付きエクスプローラ型ファイル管理アプリ UI設計書

## 1. システムアーキテクチャ・技術スタック
- **フロントエンド**: React + Vite
  - 高速な開発と将来の拡張性を担保するため、ブラウザ上で動作するUIとして開発を進める。
- **スタイリング**: Vanilla CSS + CSS Variables
  - 独自のデザインシステムを構築し、プレミアムな外観を作り込む。
- **将来的なパッケージング**: Electron または Tauri
  - ReactアプリとPythonバックエンドをデスクトップアプリとして1つにパッケージングすることを前提とした設計。

## 2. デザイン・UI方針（Aesthetics）
- **Premium & Native App Feel**: 有料ソフトウェアとして販売できるレベルの高品質で洗練されたデザイン。単なるWebページではなく、OSネイティブアプリのような固定レイアウト（ブラウザ特有の不要なスクロールがない状態）とソリッドな操作感を実現する。
- **テーマ対応**: CSS Variables（`--bg-color`, `--text-color` 等）を用いて、ダークモードとライトモードのシームレスな切り替えを実現する。
- **インタラクション**: ホバー時のエフェクトや、ファイル選択時のスムーズなアニメーション（マイクロインタラクション）を実装し、リッチなUXを提供する。

## 3. 画面レイアウト構成
OS標準のエクスプローラに高度な検索機能を統合したレイアウトを採用。（チャット用のペインは廃止）

1. **ファイルエクスプローラ領域**
   - **階層ツリービュー**: フォルダ階層をツリー状に表示するサイドバー。
   - **ファイル一覧**: 現在のディレクトリ内、または検索結果のファイル一覧を表示するメインエリア（リスト/グリッド表示に対応）。
   - **パス＆検索バー**: 現在のパスを表示するパンくずリストと、強力なファイル検索を実行できる検索入力フォームの統合。
2. **クイックコマンドパレット（Spotlight風ウィンドウ）**
   - メイン画面の上にフローティング表示されるオーバーレイUI。ショートカットキーで即座に起動・非表示を切り替え。
   - テキスト入力欄と、直下にサジェスト（ファイル検索結果等）を表示するシンプルで洗練されたデザイン。

## 4. UIコンポーネント設計（React）
- `Layout`: 画面全体の枠組み（エクスプローラメインのレイアウト）。
- `ExplorerPane`: エクスプローラUIの親コンポーネント。
  - `DirectoryTree`
  - `FileList` (通常時および検索結果表示を兼ねる)
  - `NavigationBar`: パス表示（`Breadcrumb`）と検索バー（`SearchBar`）を含むヘッダー部分。
- `CommandPalette`: ショートカットで呼び出されるSpotlight/Raycast風のモーダルコンポーネント。
